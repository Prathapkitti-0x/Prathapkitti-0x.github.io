# Prathapa K — Personal Portfolio

A free, recruiter-friendly personal portfolio website built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — website content
- `style.css` — design
- `script.js` — mobile menu and smooth scrolling
- `resume.pdf` — add your PDF resume here

## Before publishing

Open `index.html` and replace:
1. `your.email@example.com` with your real email.
2. `https://www.linkedin.com/` with your LinkedIn profile URL.
3. `resume.pdf` with your resume file (keep the filename `resume.pdf`).
4. Any project details/links you want to change.

## Publish FREE with GitHub Pages

1. Create a GitHub repository, for example `portfolio`.
2. Upload all files in this folder.
3. Go to the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide your public website URL.

Your URL will normally look like:

`https://Prathapkitti-0x.github.io/portfolio/`

If you name the repository `Prathapkitti-0x.github.io`, the URL can instead be:

`https://Prathapkitti-0x.github.io/`
